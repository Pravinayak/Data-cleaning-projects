# E-Commerce Purchases Data Analysis 📊

An end-to-end data analysis project on E-Commerce customer purchase data using **Python + Pandas**.  
This project explores customer behavior, purchase patterns, and key business insights from 15 different types of analysis.

## 📌 Project Overview
E-commerce companies generate massive amounts of transaction data daily. This project aims to analyze the `Ecommerce Purchases.csv` dataset to understand customer purchasing trends, identify top products, peak purchase times, and derive actionable insights for business growth.

**Tools Used**: `Python 3.9`, `Pandas`, `Jupyter Notebook`, `NumPy`, `Matplotlib`

## 📁 Dataset
- **File**: `Ecommerce Purchases.csv`
- **Source**: Kaggle / Sample E-commerce Transaction Data
- **Columns**: `Email, Address, Purchase Price, Language, Job, Credit Card, IP Address, Browser Info, Purchase Date` etc.

## 🔍 15 Types of Analysis Performed

1.  **Data Inspection**: `head(10)` and `tail(10)` to check first and last 10 rows
2.  **Data Types Check**: `dtypes` to understand column data types
3.  **Missing Values Analysis**: Check for nulls and handle missing data
4.  **Dataset Info**: `info()` for memory usage and non-null counts
5.  **Descriptive Statistics**: `describe()` for numerical columns summary
6.  **Unique Values Count**: Count unique customers, jobs, languages
7.  **Top Spending Customers**: Identify customers with highest purchase price
8.  **Average Purchase Price**: Calculate overall and category-wise average
9.  **Language-wise Analysis**: Most common languages used by customers
10. **Job-wise Purchase Pattern**: Which profession spends the most
11. **Time-based Analysis**: Peak purchase hours and days

13. **Find Email of the person with the following credit card number 675957666125
14. **How many people have a credit card that expires in 2020
15. ** Top 5 Most email providers (Eg.., gmail.com ,yahoo.com etc...)
